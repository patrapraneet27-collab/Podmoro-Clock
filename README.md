# ⏰ Podmoro

> A modern, completely free productivity clock inspired by premium focus apps.

## 📖 About

Podmoro is an open-source productivity clock designed to provide the features found in premium focus applications—without requiring a subscription.

Many popular focus and Pomodoro apps lock useful features behind paywalls. Podmoro aims to make those features freely available to everyone while maintaining a clean, modern, and customizable experience.

This project is currently under active development, and new features will be added over time.

---

## 🎯 Vision

The long-term goal of Podmoro is to become a complete productivity companion by offering features such as:

- ⏱️ Pomodoro Timer
- 🕒 Clock
- 🎵 Music Integration
- 🎥 Video & Image Backgrounds
- 🎨 Custom Themes
- 📊 Productivity Statistics
- ☁️ Cloud Sync
- ✅ Task Management
- 🔔 Notifications
- 📅 Calendar Integration
- ...and many more.

The aim is simple:

> **Create a powerful productivity application that rivals premium apps like Flocus while remaining completely free and open-source.**

## 🚧 Project Status

**Current Status:** 🛠️ In Development

This repository contains the work-in-progress version of Podmoro.

Not every planned feature has been implemented yet, and some parts may be incomplete or change significantly over time.

Updates may not always be frequent because this project is being developed alongside my studies, but development has **not** been abandoned.

If you don't see a feature yet, don't worry—it is likely planned for a future update.

## 💡 Why Open Source?

I believe productivity tools should be accessible to everyone.

Instead of hiding useful features behind subscriptions, Podmoro is being built as a community-friendly project where anyone can:

- Explore the code
- Learn from it
- Suggest improvements
- Contribute to its future
